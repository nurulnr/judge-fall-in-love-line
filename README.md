One line, 240 characters at most, to make the judge fall for a person, a place, a machine or an idea. Entries are judged two at a time and the lines that move the judge hardest take the reward.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the entry line to `entry.txt` in the output directory. The line is fixed text, 121 characters, so the output is byte-identical on every run and uses no network.
